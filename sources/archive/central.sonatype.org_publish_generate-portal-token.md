You must use a user token to publish artifacts to the Central Repository via the Central Publisher Portal.

1.  Log in to the Central Publisher Portal and navigate to the user tokens page at [https://central.sonatype.com/usertoken](https://central.sonatype.com/usertoken) ![A screenshot of the user tokens page that shows the Generate User Token
    button](../../images/portal-token-usertoken-page.png "A screenshot of the user    token page that shows the Generate User Token button")
2.  Press the **Generate User Token** button
3.  Specify a display name and an expiration for the token ![A screenshot of the
    user token generation popup that shows the Name and Expiration Date settings](../../images/portal-token-create-popup.png)
4.  Save the generated credentials for use in your publishing setup ![A Screenshot of the modal that displays the user token once it has been
    generated](../../images/portal-token-view-popup.png "A Screenshot of the modal that displays the user token once it has been    generated")

Token access

Tokens cannot be retrieved once the modal closes, so it is a publisher's responsibility to maintain control of the token or generate a replacement as needed.
